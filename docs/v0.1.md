# v0.1 scope

## Required user journey

1. A user starts Claude Code in a repository and asks it to start AGSV. Embedded defaults work without changing the repository; `agsv init` is optional customization.
2. The AGSV skill registers the current Claude session as the active Primary.
3. The Herdr backend starts or resumes a Codex Implementation Orchestrator without duplicating a healthy actor.
4. The Primary sends a typed implementation request.
5. The Implementation Orchestrator returns progress, blockers, evidence, and an immutable candidate SHA.
6. The Primary runs provider-native fresh review and sends an accepted or rejected decision.
7. A rejection produces a fix request and a new candidate/review cycle.
8. The user asks the Primary to create another team. A separate Implementation Orchestrator starts in another Herdr tab and both teams progress concurrently.
9. The Primary and all implementations can discover and exchange scoped cross-team messages through the shared workspace mailbox.
10. Daemon or orchestrator restarts preserve unacknowledged work and reject late stale-epoch results.

## Required CLI surface

- `agsv init`
- `agsv start`, `stop`, `status`, `doctor`, `attach`, `events`
- `agsv team create|list|show|pause|resume`
- `agsv actor list|show|stop|replace`
- `agsv run create|list|show|pause|resume|cancel`
- `agsv request create|list|show|claim|block|complete|cancel`
- `agsv message send`, `inbox`, and `ack`
- `agsv decision submit`
- `agsv context --bootstrap`
- `agsv reconcile`
- `agsv config show|validate`
- JSON output for all commands used by agents

The final spelling may be refined while preserving these domain operations.

## Required quality

- GitHub Actions runs formatting, Clippy with warnings denied, and the full workspace test suite on every pull request and push to `main`.
- Dependencies are selected from the latest compatible stable release at the time they are introduced, with the resolved graph committed in `Cargo.lock`.
- Rust unit tests cover legal and illegal state transitions, authorization, epoch fencing, and idempotency.
- Integration tests cover daemon persistence and concurrent clients.
- A fake session/runtime backend covers the full Primary-to-two-Implementation flow deterministically.
- Live smoke tests cover Herdr plus authenticated Claude Code and Codex without requiring GitHub APIs.
- `skills/agsv` is valid for skills.sh discovery and teaches agents to use CLI state rather than editing runtime files.
- `agsv init` is idempotent and never overwrites project-owned role changes silently.
- A no-config repository uses embedded roles/configuration and user-scoped runtime state without writing any repository file.

## Excluded

- Provider-native subagent lifecycle management.
- GitHub Milestone or Issue synchronization.
- Automatic push, merge, or issue closure.
- Web dashboard and custom TUI.
- Windows support.
- A general plugin SDK beyond the traits required by the initial fake, process, Herdr, Claude Code, and Codex adapters.
